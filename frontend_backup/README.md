# 🎨 GEM Frontend Web Application

Giao diện Người dùng Tương tác (UI/UX) cho Hệ thống Cố vấn Ý tưởng Đồ án & Định hướng Nghề nghiệp IT (GEM - AISC 2026).

---

## 📌 Công nghệ Sử dụng
* **Core:** React 18 + TypeScript
* **Build Tool:** Vite 5
* **Icon Set:** Lucide React
* **Styling:** Modern CSS (Glassmorphism, Dark Mode, Responsive Design)

---

## 🚀 Hướng dẫn Cài đặt & Khởi chạy

```bash
cd frontend

# Cài đặt các dependencies
npm install

# Khởi chạy server phát triển (Dev server)
npm run dev
```

Ứng dụng sẽ khả dụng tại: [http://localhost:5173](http://localhost:5173)
